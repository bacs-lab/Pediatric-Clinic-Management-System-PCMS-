# Ownership and Review

Required review areas before production:

- Owner/product approval for scope and workflow behavior.
- Clinical representative approval for clinical-record lifecycle and release rules.
- Privacy/security approval for data handling, retention, access review, audit, and incident response.
- Technical approval for architecture, migration, test evidence, and rollback.

Protected `main`, required CI, dependency/security scanning, and branch protection must be configured in the repository settings by an owner.
