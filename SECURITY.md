# Security Policy

Do not report PHI, credentials, tokens, database dumps, production URLs, signed URLs, screenshots containing patient data, or exploitable details in public issues or pull requests.

For security or privacy concerns, contact the repository owner through an approved private channel. Rotate any exposed credentials immediately; deleting a committed secret from the current tree is not sufficient remediation.

Supported branch for v2 work: `feat/pcms-v2-supabase-replatform`.
